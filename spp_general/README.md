# 🌐 Quantum Network & Percolation Simulators  

📦 This repository gathers different implementations related to:  
- **Quantum Networks**  
- **Shortest Path Percolation (SPP)**  

Each implementation is available in **two forms**:  
1. **📑 Simulator** → Python structured code, ready to run via CLI (`main.py`) or to be integrated into other projects.  
   - Each **simulator folder** contains its own **README**, explaining **step by step how to execute** the implementation.  
2. **📓 Notebook** → Equivalent version in Jupyter/Colab, designed for those who prefer interactive execution.  
   - Each **notebook** includes **general explanations about what is being developed**, making it more didactic and user-friendly.  

---

## 📂 Structure  

```
.
├── quantum-network-simulator/   # Main implementation of the quantum network simulator (with execution README)
├── quantum-network-notebook/    # Notebook version with general explanations
├── spp-general-simulator/       # General implementation of the SPP percolation model (with execution README)
└── spp-general-network/         # Notebook version with general explanations
```


---

## 🔑 Important Note  
Folders with **`notebook`** in their name contain exactly the **same implementations** as the corresponding **`simulator`** folders.  
- The purpose of the notebooks is to provide **didactic explanations and step-by-step demonstrations**.  
- The simulators are recommended for **large-scale execution** and come with an **internal README containing detailed usage instructions**.
