# 🔬 General Percolation Simulation (SPP)

📦 This directory contains the implementation of the **general percolation dynamics (SPP)** with different types of **attacks** applied to the network. The organization separates results generated via **notebooks** — useful for those who may not be familiar with command-line execution. In addition, this code can be easily run in **Anaconda** or **Google Colab**.

## 📓 Notebooks
- **spp-general.ipynb** → Implements the general percolation dynamics with several attack strategies (random, targeted, load-based, etc.), including step-by-step explanations.  
- **plot-spp-general.ipynb** → Shows how to **plot the executed dynamics**, generating visualizations of the network evolution under attacks.  

## 📂 Structure
bash
```
.  
├── data_notebook/N1500/                    # Results from executions using notebooks  
├── data_simulator/N1500/random1-random2/   # Results from executions using the simulator (CLI)  
├── network-save/                           # Saved graphs (e.g., ER1500-graph.txt)  
├── plot-spp-general.ipynb                  # Notebook for plotting the dynamics  
└── spp-general.ipynb                       # Notebook for general percolation dynamics  
```
